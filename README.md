# typing-girl

A Claude Code mod for the Claude desktop app that gives Claude a face: Claude大小姐, the orange-haired personification the Chinese community gave Claude. This is a fan-made mod, not an Anthropic product.

## What it does

- **Typing girl:** while Claude works, she sits under your newest message in the chat and types on her laptop, then leaves when the turn ends.
- **Tiny runner:** in the row with the thinking dots, a small running version of her appears beside the status words. The app keeps its own dots and gives that row one line of height, so she runs beside them.
- **Side panel:** `/claude-panel` opens a panel beside the chat with a picture of her and an "Another one" button.
- **Check tool:** Claude can call `draw_report` to see how often the app asked the mod to draw, to confirm she is on screen.

A terminal keeps its normal spinner, because it cannot draw pictures. The VS Code extension has the same drawing element but has not been tried.

## Best used together with

This mod only changes how Claude looks. For Claude to also talk like her and send her stickers, use it together with the persona prompt and the sticker skill by their original author:

- **Persona prompt and sticker skill (kelaode):** https://github.com/Brian5201314-520007/kelaode-persona-stickers

The persona goes into Settings → Your Claude → Instructions (Chat app) or a personal `CLAUDE.md` (Claude Code); the sticker skill is uploaded under Customize → Skills. Those files are not included here: the stickers are personal-use only under their own licence.

## Install

At the prompt of a terminal session:

```
/plugin install typing-girl --marketplace Janson1212/ClaudeAnim
```

Answer `y` to add the marketplace, then choose a scope (the user scope shows her in every session).

From a shell:

```
claude plugin install typing-girl --marketplace Janson1212/ClaudeAnim
```

In the Claude desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `Janson1212/ClaudeAnim`, then Add plugin.

This repository is private. It installs only for people who can read it on GitHub and whose computer already holds a git credential for github.com (an SSH key, or `gh auth login` then `gh auth setup-git`). The install never asks for one.

## Change her

- **Size:** `GIRL_HEIGHT` in `hooks/girl.ts` (typing girl) and `RUNNER_HEIGHT` in `hooks/runner.ts`, in pixels.
- **New pictures:** `hooks/girl.ts` and `hooks/runner.ts` are generated by `cutout.py`, which removes the white background from a typing picture and a running GIF and embeds them. Edit the script's file names and run it again rather than editing those two files.
- **Panel stickers:** `stickers.py` rewrites `hooks/stickers.ts` with small copies of a few stickers from the kelaode pack (personal use only; don't share the result).
- **Where she appears:** the hooks are in `hooks/register.tsx`.
- **Tests:** `claude plugin test <this folder>`.
